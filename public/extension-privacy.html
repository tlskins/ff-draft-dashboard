Drafty Draft Sync Privacy Policy

Effective August 30, 2026

Drafty Draft Sync has one purpose: relay live fantasy-football draft information from supported ESPN and NFL.com draft rooms to an open Drafty dashboard tab.

Information the extension handles

On the supported draft-room pages listed in the extension manifest, the extension reads only information needed to synchronize the draft:

  • drafted player name, team, position, pick coordinate, and pick order;
  • draft title, platform, league identifier present in the page URL, team count, user roster position, scoring format, and completion state when available;
  • the supported draft page URL and bounded selector-health diagnostics needed to identify the session and report whether capture is working.

This is website content and narrowly scoped browsing activity. The extension does not read passwords, authentication cookies, private messages, payment information, general browsing history, or pages outside its declared Drafty, ESPN draft, and NFL.com draft matches.

How the information is used

The extension uses Chrome runtime ports to relay the draft snapshot to an open Drafty dashboard tab. It does not sell data, use it for advertising or credit decisions, or transfer it to data brokers.

The extension itself makes no external network requests, uses no analytics service, executes no remote code, and writes no draft data to Chrome extension storage. Its in-memory relay state is discarded when the relevant tabs or extension worker close.

Drafty account persistence

The Drafty web application can be used locally without signing in. If a user signs into Drafty and enables its account-backed features, the web application—not the extension—may transmit season-scoped rankings, targets, and completed mock-draft results over HTTPS to Drafty's Google Cloud services. The extension does not receive Google credentials or authentication tokens.

Sharing and limited use

Information is used only to provide or improve the disclosed draft-synchronization feature, operate it securely, and diagnose capture failures. Human access is limited to a user's explicit support request, security needs, or legal obligations.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Retention and deletion

The extension does not retain draft information after its in-memory browser session. Drafty account data is grouped by fantasy season. For questions, support, or an account-data deletion request, use the Drafty extension support page. Do not place private account information in a public issue.

Changes

Material changes to the extension's data practices will be reflected in this policy and disclosed through the extension or its Chrome Web Store listing before the changed practice begins.
