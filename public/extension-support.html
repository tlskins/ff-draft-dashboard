Install and use Drafty Draft Sync

Drafty Draft Sync relays live ESPN and NFL.com fantasy-draft picks to an open Drafty dashboard. Version 0.0.0.11 is approved and available from the Chrome Web Store.

Install Drafty Draft Sync

Get connected

  1. Install the extension in the same Chrome profile you use for fantasy drafts.
  2. Open Drafty and your supported ESPN or NFL.com draft room in that Chrome profile.
  3. If the draft was already open when you installed the extension, reload both tabs once.
  4. When Drafty detects the room, choose Connect beside the draft in the bottom dock.
  5. Keep both tabs open during the draft. Drafty will update as picks arrive.

Signing in to Drafty is optional for live pick capture. Sign in only if you want rankings, targets, and completed mock reviews synchronized across devices.

If Drafty cannot see the draft

  1. Open the extension popup and confirm it says Drafty Draft Sync version 0.0.0.11.
  2. Confirm the extension is enabled at chrome://extensions.
  3. Reload the Drafty and draft-room tabs; then return to Drafty and select the detected draft.
  4. Remove or disable older local copies such as FF Draft Pulse so only one Drafty capture extension is active.
